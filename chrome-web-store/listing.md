# Privacy practices

## Single purpose

STUPIDLY lets users set and enforce session and daily time limits for websites, with an optional delay before existing limits can be changed.

## Permission justifications

### storage

Stores the user's configured domains, session and daily limits, redirects, settings delay, and local usage needed to enforce daily limits. This data stays in Chrome and is not sent to a server.

### alarms

Schedules session expirations, daily-limit checks, and the midnight reset without keeping a background process continuously running.

### webNavigation

Detects top-level page loads on configured websites so STUPIDLY can start a new session timer and enforce the user's limits.

### declarativeNetRequest

Blocks or redirects configured websites after the user reaches a daily limit using Chrome's built-in declarative network rules.

### host permissions

Users can limit any website, so STUPIDLY needs access to HTTP and HTTPS URLs to recognize configured domains and enforce the limits the user sets.
