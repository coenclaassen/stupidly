# Privacy practices

## Single purpose

SiteLimit lets users set and enforce session and daily time limits for websites, with an optional delay before existing limits can be changed.


## Permission justifications

### alarms

Schedules session expirations, daily-limit checks, and the midnight reset without keeping a background process continuously running.

### declarativeNetRequest

Blocks or redirects configured websites after the user reaches a daily limit using Chrome's built-in declarative network rules.

### host permissions

Users can limit any website, so SiteLimit needs access to HTTP and HTTPS URLs to recognize configured domains and enforce the limits the user sets.

### storage

Stores the user's configured domains, session and daily limits, redirects, settings delay, and local usage needed to enforce daily limits. This data stays in Chrome and is not sent to a server.

### webNavigation

Detects top-level page loads on configured websites so SiteLimit can start a new session timer and enforce the user's limits.
